# Checkpoint 86 — Base corrigida do checkpoint 80

Este checkpoint restaura a origem correta do ELVANOQ 2.17.2 após a detecção
de que um APK anterior havia sido compilado de uma base anterior ao checkpoint
80.

Validações realizadas:

- busca presente nas abas Filmes e Séries;
- controles do player com áreas seguras, avanço/retrocesso e barra de tempo;
- ações de série **Pular abertura** e **Próximo episódio**;
- logo de login ampliada e texto promocional removido;
- testes de player e navegação aprovados.

O próximo APK deve ser gerado exclusivamente a partir desta base.
