# Instalação e atualização — FlixPlay 2.15.0

## Instalação limpa

1. Copie o APK universal para o aparelho.
2. Autorize a instalação pela origem escolhida somente para essa ação.
3. Instale o APK e abra o FlixPlay.
4. Cadastre uma fonte autorizada e valide TV ao vivo, filmes e séries.

## Atualização preservando dados

1. Não desinstale a versão existente.
2. Faça backup operacional antes da atualização quando disponível.
3. Instale o APK 2.15.0 sobre a instalação atual.
4. Confirme que listas, favoritos, histórico, progresso e preferências permanecem disponíveis.

A atualização exige o mesmo package e o mesmo certificado. Se o Android informar conflito de assinatura, interrompa o processo; desinstalar apagará os dados locais.

## Verificações mínimas

- Versão exibida: 2.15.0 / build 20261006.
- Package: `com.fastshot.slitherproduction.flixplay`.
- ABIs: `armeabi-v7a` e `arm64-v8a`.
- Android: API 24 ou superior.
