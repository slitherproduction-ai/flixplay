# Matriz de compatibilidade — FlixPlay 2.15.0

Esta matriz separa configuração pretendida de compatibilidade comprovada. “Configurado” não equivale a “homologado”.

| Plataforma | Requisito | Configuração do projeto | Homologação física | Status |
|---|---|---|---|---|
| Android smartphone | API 24+ | Configurado | Pendente | Não homologado |
| Tablet Android | API 24+ | Configurado | Pendente | Não homologado |
| Android TV | API 24+, D-Pad | Configurado | Pendente | Não homologado |
| Google TV | API 24+, D-Pad | Configurado | Pendente | Não homologado |
| Fire TV/FireStick | Compatibilidade Android | Configurado | Pendente | Não homologado |
| `armeabi-v7a` | APK/AAB nativo | Planejado | Build final pendente | Não validado |
| `arm64-v8a` | APK/AAB nativo | Planejado | Build final pendente | Não validado |
